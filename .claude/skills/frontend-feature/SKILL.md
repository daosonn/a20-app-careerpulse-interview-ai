# Skill: Frontend Feature Implementation

## Purpose
Build or modify React UI in the existing CareerPulse design system.

## Process
1. Locate the owning feature folder.
2. Reuse shared UI components and colors.
3. Use `authenticatedFetch()` for protected backend calls.
4. Keep loading, empty, error, and disabled states.
5. Preserve responsive behavior and sidebar/full-viewport route boundaries.
6. Run `cd frontend && npm run lint`; build when contracts/assets changed.

## Boundaries
- Do not add a new UI framework.
- Do not expose secrets in client code.
- Do not rewrite copy encoding broadly unless requested.
