# Skill: Feature Implementation

Use when adding or changing user-visible behavior.

Process:
1. Locate owner files.
2. Trace data path.
3. Update backend schema/endpoint/service or frontend component/hook as needed.
4. Keep types and response fields aligned.
5. Validate with lint/build/check commands.

Output:
- Changed files.
- Behavior changed.
- Validation result.
- Remaining risks.
