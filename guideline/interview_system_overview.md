# Implementation Plan - Dynamic Batch-Based Questions & Tip-Enhanced UI

This plan implements a dynamic interview flow where questions are generated in 3 batches of 3 questions each. Each question includes an answering tip (label) for the candidate and a model answer for backend evaluation.

## User Review Required

> [!IMPORTANT]
> - **Question Flow**: 3 batches of 3 questions (total up to 9).
> - **Evaluation**: Stays real-time (after every question), but now uses a specific "Model Answer" generated by the AI for each question to improve accuracy.
> - **Answering Tips**: Each AI question will now have a small navy-colored "Tip" tag displayed below it on the frontend.
> - **Manual Termination**: The "End" button will still work as expected, triggering the final report generation.
